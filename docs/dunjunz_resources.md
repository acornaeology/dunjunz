# Dunjunz Maps

BBC Micro Games Archive: https://bbcmicro.co.uk/game.php?id=1068  (Note: I think the sideways RAM is used to contain ROMFS transcriptions of the original cassette version)

GPL 3.0 tools by David Boddie for working with Dunjunz maps: https://github.com/stardot/DunjunzMaps/tree/master/DunjunzMaps

The Dunjunz Compatibility Matrix on Stardot: https://stardot.org.uk/forums/viewtopic.php?f=1&t=13214#p172123

A port to the 6809 (Dragon) based on the BBC Version. Includes buildabl source.


Stardot thread on Dunjunz versions and DFS compatibility: https://stardot.org.uk/forums/viewtopic.php?t=16227 (notes in `stardot-dunjunz-versions-thread.md`)

Historical archives: https://rk.nvg.ntnu.no/bbc/sw/BugByte/Dunjunz.zip (disc release with level editor, both sides) and https://rk.nvg.ntnu.no/bbc/sw/BugByte/Dunjunz-tape.zip (tape release)
